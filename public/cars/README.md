# Car Images Folder

Place all car images here.

## How to add/replace a car image:
1. Copy your image file into this folder: /public/cars/
2. Name it exactly as defined in /src/data/fleet.ts (e.g. dacia-sandero.jpg)
3. The website will automatically display it.

## Supported formats:
.jpg, .jpeg, .png, .webp

## File naming convention:
Use lowercase, hyphens instead of spaces.
Examples:
  dacia-sandero.jpg
  audi-a3.jpg
  volkswagen-golf-8.jpg
